Step 1

Installation

Copy the addon folder into CraftEngine's resources folder and reload.

Step #1

Copy the CustomTiers_CraftEngine folder into: 

plugins/CraftEngine/resources/

The structure should look like this:

plugins/
└── CraftEngine/
    └── resources/
        └── CustomTiers_CraftEngine/
            ├── pack.yml
            ├── configuration/
            └── resourcepack/

Step #2

If the server is running:

/ce reload all

Next: create your first item with the model_path template.
