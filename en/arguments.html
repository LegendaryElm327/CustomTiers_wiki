Basic arguments

All templates use the custom_tiers:tiers formatter. These are the arguments you can pass to it.

Common arguments

ArgumentRequiredDescription
typeYesWhich template is used: model_path, model_path_bow, model_path_crossbow, etc.
tiersYesNumber of possible tiers, from 1 to 7. (Use only the ones you need.)
displayNoTier shown by default. If omitted, there is no background until the MMOITEMS_TIER key gets an existing value.
tier_1 … tier_7NoName of each tier. Defaults: common, uncommon, rare, epic, legendary, mythic, unique. You can rename the 7 slots to your liking.

Full example

items:
  custom_tiers:my_sword:
    material: diamond_sword
    template:
    - custom_tiers:tiers
    arguments:
      type: model_path
      tiers: 3
      display: rare
      tier_1: rare
      tier_2: legendary
      tier_3: unique
      model_path: minecraft:item/diamond_sword

The formatter creates an item with 3 possible tiers: rare, legendary and unique.

About display and tiers

tiers defines how many values the item accepts. display is the concrete value written to MMOITEMS_TIER.

ConfigurationResult
tiers: 3 + display: rareThe item starts with the RARE tier hardcoded if you get it from CraftEngine.
tiers: 3 + display: uncommonNo background. In the previous example we did NOT define uncommon as a possible tier.
No displayThe item shows no background until another plugin writes MMOITEMS_TIER.

Available types

  • model_path — Existing model (food, block, etc.).
  • model_path_bow — Bow.
  • model_path_crossbow — Crossbow.
  • model_path_fishing_rod — Fishing rod.
  • model_path_shield — Normal shield with blocking (no banner patterns).
  • trident_model_path / trident_auto — Working trident.
  • armor_generated — Armor without trims.
  • trim_armor_generated — Armor with trims.

Examples for each type are in Creating weapons and Creating armor.
