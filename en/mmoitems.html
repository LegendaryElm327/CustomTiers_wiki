Step 4

Connect with MMOItems

The connection is simple: create the item in CraftEngine, then select that item model in MMOItems using the same namespace:ID.

1. Create the item in CraftEngine

The item and its model must exist first. For example:

items:
  custom_tiers:my_sword:
    material: diamond_sword
    template:
    - custom_tiers:tiers
    arguments:
      type: model_path
      tiers: 3
      display: rare
      model_path: minecraft:item/diamond_sword

Reload and check that the item can be given:

/ce reload all
/ce item get custom_tiers:my_sword

2. Select the item model in MMOItems

In the MMOItems item configuration, select the CraftEngine item model. The only important part is that the namespace:ID matches exactly:

item_model: custom_tiers:my_sword
  • custom_tiers is the pack namespace.
  • my_sword is the ID of the item you created.

3. Set the tier

The background appears when the item has MMOITEMS_TIER with a value that matches one of the configured tiers. You can:

  • Set a fixed tier with display in CraftEngine, or let MMOItems write MMOITEMS_TIER.
KATANA:
  base:
    material: DIAMOND_SWORD
    name: '&fKatana'
    item_model: custom_tiers:my_sword     # IMPORTANT
  modifiers:
    critical_strike_group:
      min: 1
      max: 1
      modifiers:                      # Make sure to add the modifiers,
        mod_common:                   # otherwise there will be no rarities.
          chance: 0.4
          stats:
            tier: COMMON
            critical-strike-chance: 5
        mod_uncommon:
          chance: 0.3
          stats:
            tier: UNCOMMON
            critical-strike-chance: 10
        mod_rare:
          chance: 0.3
          stats:
            tier: RARE
            critical-strike-chance: 15
The ID must match

Check that your item model is correct before asking for help.
